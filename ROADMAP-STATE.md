## 🆕 #8 — Мишина ДВУХУРОВНЕВАЯ КАРТА (его чертёж, 2026-07-17, НЕ ПОТЕРЯТЬ)

Пришёл полный пейст Миши. Свежак, в старом «Интел Миши» его НЕТ — снапшот тут, чтоб не сгинул.
Не глубина-под-воду, не drill-down — **ДВА РАЗНЫХ ГРАФА над одними нодами, разведённые по
семантике рёбер**. Керн, который прошлые чтения проебали: **типизация нод**.

**Тезис (его слова):** Obsidian смешивает membership и context в один граф → при масштабе = каша.
Разведи их в две карты → чисто. «схожі слова тяжіють до родичів» — норма, не баг.

**Типизация нод (А/В/С, до 4 уровней):**
- **Тип А** (высший, центрирующий) = предмет (общая психология, возрастная, гендерная).
- **Тип В** (распределяющий) = темы предмета (мышление, память…).
- **Тип С** (подтемы, деталь В) = типы/особенности/разновидности.
- 4-й уровень — для особых нужд, редко >4.

**Карта 1 — чистый радиальный скелет (для человека):** А в центре → орбита В → у В орбита С.
Рёбра ТОЛЬКО membership (родитель→ребёнок). Один А = ноль артефактов.

**Карта 2 — контекст-паутина (под капотом):** рёбра по содержанию статей, пересекают группы
СВОБОДНО. Его наблюдение (ключ): нода С может иметь БОЛЬШЕ рёбер с чужим В — **и это нормально,
прописку не меняет**. membership ≠ context-degree. ← вот что Obsidian конфлейтит.

**Развязка = смерть каши:** новый А на карте1 линкуется только с А; на карте2 — с чем угодно.

**UX:** тычешь карту1 → наводишь ноду → правое окно (**мультивикно**) даёт её карту2 +
градация коэффициентов связей. Right-panel идея — от того Obsidian-плагина.

**Статус в коде:**
- карта2-данные ЕСТЬ (edge kind=semantic/tag_overlap/temporal/homology) + панель #2 (список).
- карта1 НЕТ: у нод только плоская `zone` + type=memory/ghost, нет tier А/В/С, нет радиал-layout.
- Раскладка = самописный canvas-force (cell-grid), не d3.force.

**Развилка масштаба (откуда берутся типы — flat 2300 глоссарий Миши иерархии НЕ несёт):**
- (a) **folder-depth** — tier = глубина подпапки. Бесплатно, если Миша вложит вульт. MVP-путь.
- (b) **auto-infer** — LLM классифицирует 2300 терминов в А/В/С. Тяжело = отдельный воркфлоу (3 опуса).
- (c) **ручная курация** — UI назначает tier кликом. Средне.

**План (эмердж, натив, оба-вида+тумблер):**
- MVP (доказать механику, Bellard): tier-поле + карта1 радиал-layout + нативный тумблер
  GRAPH→[taxonomy‖context‖overlay], на demo/folder-depth. Доказать «каша→чисто».
- Follow-on: типизация 2300 (b/c) — воркфлоу, НЕ этот проход.
