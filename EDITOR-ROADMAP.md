# memory-atlas → editor: emergent ideas & state

Дамп сессии 2026-07-17 (вьювер → редактируемый инструмент). Не спека — карта того, что
проявилось в интенте, и куда оно тянет. Приоритет = по силе тезиса, не по лёгкости.

---

## Продукт-тезис (то, что реально проявилось)

**Atlas превращает плоский, нелинкованный корпус в живой связанный граф знаний:
машина ПРЕДЛАГАЕТ структуру, которую вывела (рёбра, теги, линки, кластеры), человек
ПРИНИМАЕТ одним кликом, и каждое принятие пишется на диск.**

Это фьюз двух ролей, которые весь исходный план держал раздельно: *observatory*
(выводит рёбра, которых автор не писал) + *editor* (правит файл). Направление юзера
«вьювер нужно редачить» РАЗРЕШИЛО старую развилку «Obsidian=дом vs Atlas=обсерватория»:
Atlas становится домом тоже.

Для Миши (плоская пдфка 2300 терминов, ноль авторских линков): импорт → atlas
предлагает линки/теги/кластеры → Миша курирует кликами → плоское становится
навигируемым. Вся дуга сессии в одном предложении.

## Что построено и ПРОВЕРЕНО (не вайб)

- **Импорт-консервация** — `chunk_glossary` больше не роняет длинные/defless/слитные
  статьи. Замер: 1900/1900 + демо 12/12, обе формы (blank-sep и слитная).
- **Сайдкар `atlas-serve`** — диск-правка из статичного HTML (save/rename/move/tags),
  path-guarded, 18/18 E2E. Клайм «no server» снят честно (docstring правлен).
- **Авто-синк** — правка → debounce → regen+reload, таб+нода восстанавливаются.
  Ключевое: **sha-cache эмбедов** (`emb-cache.json`) → re-embed ТОЛЬКО изменённого
  текста (тег/зона = 0 нот, rename/тело = 1). Не гоняет Ollama по вульту.
- **Тег = один, на диске.** Оверлей-разделение (userTags localStorage) убито по решению
  юзера: «тэги личная метка, больший вес; правка тега = правка файла».
- **Редактор-тулбар** — B/I/`[[ ]]` + дабл-клик по телу → правка. CDP-проверено:
  выделил → B → `**обёрнуто**`.
- **Тихий неон + объём** — inset-хайлайт + градиент + неон-край, backdrop-blur; без
  диффузного глоу.
- **CDP-харнесс** (`scratchpad/cdp.py`) — headless chromium на Арче + WS-CDP → драйв
  DOM, само-верификация правок без раундов юзера. ЭТО меняет весь loop разработки.

## Эмердж-фичи (по силе)

### 1. Bookmark-дуга → извлечение концепта  ⭐ killer для Миши
Выделил текст → (a) **закладка**: неон-глоу на тексте + язычок сбоку, клик сдвигает-
открывает цитату как Quote (левый бар); ИЛИ (b) **извлечь в новую ноту**: заголовок =
выделение, тело ниже, автолинк назад. Вариант (b) — мост плоское→граф: читая пдфку,
Миша хайлайтит определение → оно становится своей нотой, слинкованной. Корпус
превращается в граф через ЧТЕНИЕ.

### 2. Suggest→accept петля (обсерватория встречает редактор)  ⭐ уникальное atlas
Atlas УЖЕ считает, что думает: semantic-соседи, tag-когорты (тот «122 тег из другой
когорты»), dangling-линки. Всплыть их как ПРИНИМАЕМЫЕ предложения в редакторе:
«эти 3 ноты близки по смыслу — слинковать? [✓]», «когорта предлагает тег X —
повесить? [✓]». Клик пишет на диск. Это делает исходную ценность atlas («выводить
рёбра, которых автор не писал») ДЕЙСТВЕННОЙ. Для корпуса с нулём авторских линков —
единственный способ стать связанным.

### 3. `[[` живой автокомплит (Obsidian-паритет линковки)
Печать `[[` в редакторе → флоат-фаззи-поиск заголовков (reuse graph-поиск) → вставка
линка. С #1/#2 = atlas становится связным think-редактором, не вьювером. Момент, где
atlas перестаёт быть «только обсерватория» и становится домом.

### 4. GUI-импорт (drag-drop / кнопка «+ док»)
CLI-импортёр как кнопка в графе. Нетех-Миша роняет PDF → сайдкар гонит atlas-import +
авто-синк. «Нет кнопки добавления доков» — прямая боль.

### 5. Инкрементальный hot-swap синк (архитектура)
Вместо regen+reload на каждую правку — сайдкар патчит ТОЛЬКО изменённую ноду в живой
DATA, страница обновляется без reload (не теряя место). sha-cache уже делает regen
дешёвым; hot-swap делает его бесшовным. Убивает «reload теряет контекст».

### 6. Workspaces + settings-панель
Свитчер вультов (сайдкар отдаёт несколько) + GUI-настройки (edit-по-дефолту, тема,
эмбеддер, режим синка). Конфиг из CLI/env в UI. «Нет кнопки между воркспейсами».

### 7. Теги с ВЕСОМ
Юзер: «теги имеют больший вес». Тег не просто лейбл — несёт важность. Tag-weighted
раскладка/поиск: тяжело-тегнутый концепт тянет родственные ноты; тег как ребро
первого класса.

## Открыто / решить

- **Дискаверабилити зоны**: дропдаун показывает существующие, инпут «впиши новую»
  неочевиден (механика цела, замерено). Аффорданс.
- **Reload теряет камеру графа** — до #5 (hot-swap) паллиатив: сохранять/восстанавливать
  вид (частично сделано для browse-selection).
- **Большой вульт**: авто-синк regen секунды на 2300 (не эмбеды — парс+рендер). #5 решает.
- **Bookmark-персист**: где хранить закладки (frontmatter? sidecar-джейсон? inline-маркер
  в теле?). Решает, переживают ли они regen.
