name: waitlist-autofill
description: Auto-fills class and appointment waitlists from cancellations instead of manual outreach.
type: spec
tags: [q2]
---
When a slot opens, the next waitlisted client gets an automatic hold and a
confirmation window. It pairs with [[sms-reminders]] to notify without a phone
call. [[yoga-studio-owner]] and [[gym-regional-manager]] both requested it
independently within the same month.
