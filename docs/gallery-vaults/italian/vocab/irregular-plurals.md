---
name: irregular-plurals
description: Irregular plurals — l'uovo/le uova, la mano/le mani — that break the pattern.
tags: [irregular, a1]
---
l'uovo → le uova (masculine flips to feminine!), la mano → le mani, il dito → le dita. Exceptions worth knowing before [[articoli-determinativi]] feels safe.
