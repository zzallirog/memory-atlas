Designation given to the unidentified source of a partial print lifted from
the dock railing at Hale's Landing, catalogued as [[unmatched-partial-print]]
in the state lab's 1998 report. No match was found in any state or federal
database as of the file's last update. A faint secondary print on the
[[motel-registry-page]] pen was tested against the same donor without result.
