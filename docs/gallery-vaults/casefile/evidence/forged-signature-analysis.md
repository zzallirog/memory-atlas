Commissioned in January 1999 after [[len-okafor]] questioned a signature on a
$30,000 loan modification dated 11 November 1997. The examiner's report noted
pen pressure inconsistent with the notarized original on file with the
[[insurance-policy-photocopy]] rider. Comparison photographs were
cross-referenced against [[coroner-photos-roll-2]], though the roll's chain of
custody was never resolved.
