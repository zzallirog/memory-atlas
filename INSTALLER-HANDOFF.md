# memory-atlas → инсталлятор для Даниеля (handoff билд-сессии)

**Цель:** Даниель ставит memory-atlas, наводит на СВОЙ вульт (Obsidian/markdown), получает
самодостаточный HTML-граф. Ноль сервера, офлайн, один файл на выходе. **Хук — не «граф», а
ОВЕРЛАП + wikilinks:** генератор вскрывает связи, которых Даниель НЕ писал руками
(общие ghost-ссылки, пересечение тегов, co-edit во времени, co-touch в git, семантика) поверх
явных `[[wikilinks]]`. «Ага»-момент = «оно нашло, что эти две заметки об одном». Демо ОБЯЗАНО
показать именно это.

База: `~/src/memory-atlas` @ `main` (v2.2.0). Читать `AUDIT.md` (§2 генератор-гэпы = ровно
барьеры портабельности) перед стройкой. Генератор = Python stdlib, ~1000 стр., 28 self-тестов.

---

## 0. Что уже есть (не строить заново)

- `memory-atlas --src DIR` — любой markdown-вульт → HTML. `--data JSON|-` — произвольный граф
  (DATA CONTRACT в шапке генератора). `--out FILE`, `--no-open`, `--self-test`.
- Парсер: frontmatter + `[[wikilinks]]` (норм: lowercase, `-`/`_`, pipe-alias, `~N`-суффиксы,
  кириллица) — модель Understand-Anything. WIKILINK_RE + norm() = единственный источник семантики.
- Детекторы оверлапа: `shared_ref` (две ноты → один ghost), `semantic` (cosine Ollama-эмбеддингов),
  `tag_overlap` (Jaccard тегов), `temporal_proximity` (co-mod 24ч), `session_co_occurrence` (git co-touch),
  `structural_homology` (opt-in). Флаги `--no-*-cross`, пороги настраиваемы.
- Шаблон self-contained: инлайн d3, zero-fetch, работает по `file://`. Тег-линза (v2.2), dash, browse.

## 1. Реальность Даниеля (проектировать под неё, не под наш стенд)

- **Нет Ollama.** `semantic`-детектор (самый богатый оверлап) требует локальный Ollama+nomic.
  У Даниеля его нет → **семантика = opt-in апгрейд, НЕ дефолт**. Деградация уже есть (граф строится
  без vecs), но проверить путь «0 ollama» отдельным прогоном. Демо должно бить оверлапом БЕЗ семантики.
- **Оверлап, что работает из коробки (без Ollama):** `shared_ref` · `tag_overlap` · `temporal_proximity`
  · `session_co_occurrence` (нужен git-репо вульта) · wikilinks. Это и есть value-prop для MVP.
  Семантику подать как «поставь ollama + nomic → появятся смысловые мосты».
- **Vault = Obsidian вероятнее всего.** Отсюда прямые барьеры (см. §2).
- **ОС/Python — неизвестно.** Открытый вопрос (§5). Дефолт-предположение: есть Python 3.

## 2. Портабельность — чинить ДО упаковки (из AUDIT §2)

- **G7 EXCLUDE_DIRS** (`memory-atlas:54`): нет `.obsidian`, `.trash`, `node_modules` → на Obsidian-вульте
  генератор жуёт мусор из `.obsidian/`. **Блокер для Obsidian.** Добавить.
- **G1 портабельность src** (`:51,:723`): `DEFAULT_SRC` захардкожен под наши хосты, автодетект цепляет
  пустой `-Users-zzalli` (пойман в W5-sync). Для чужого вульта — `--src` обязателен + автодетект НЕ должен
  молча брать пустой кандидат. **Чинить: skip-empty в автодетекте + чёткая ошибка «дай --src».**
- **G2 frontmatter top-level** (`:79-87`): `tags:`/`type:` матчатся только с отступом (наш вложенный формат);
  **Obsidian кладёт `tags:` на top-level** → сейчас молча теряются, а теги = половина оверлапа. **Блокер.**
  Паттерн `^\s*key:` (оба уровня).
- **G4 `--data` валидатор** (`:682`): для «продвинутого» пути (Даниель пайпит свой JSON) — понятная ошибка
  вместо криптик-краша в шаблоне.
- **G10 `mtime:0`**: прокинуть реальный mtime → сорт по дате в browse + temporal-детектор честнее.
- Порядок: G7+G2 = P0 (без них Obsidian-вульт немой), G1 = P0 (иначе не наведётся), остальное P1.

## 3. Форма инсталлятора (выбрать, MVP → nice)

- **MVP — zipapp `.pyz`** (рекоменд): stdlib-only → `python3 -m zipapp` собирает `memory-atlas.pyz`
  (генератор + template внутри, `realpath` уже symlink-safe → упаковать template как ресурс рядом/внутрь).
  Даниель: `python3 memory-atlas.pyz --src ~/vault`. Один файл, кросс-ОС, ноль зависимостей.
- **Nice — `pipx install memory-atlas`**: pyproject + entry-point `memory-atlas`. Чистая команда, апдейты.
  Нужен Python 3 + pipx. Опубликовать в PyPI = **outward-шаг → gate (§6)**.
- **Zero-Python — PyInstaller/Nuitka бинарь** per-OS: только если у Даниеля нет Python. Тяжело, отложить.
- Не тащить веб/npm — против bellard, это stdlib-скрипт.

## 4. Демо-вульт («запихнуть свой или тестовый»)

**НЕ реальный приватный вульт** (self-contained HTML вшивает тела нот → это утечка наружу, ядро 05/08).
**Синтетический демо-вульт** — крафт под «ага»-оверлап, ноль приватности:
- 2 тематических кластера (напр. «cooking» и «chemistry») внешне не связанных wikilinks.
- **Скрытый мост:** обе зоны `[[ссылаются]]` на одну несуществующую ноту (`[[maillard-reaction]]`) →
  `shared_ref` рисует ghost-перемычку = «оно нашло общее». + пара общих `tags:` → `tag_overlap`.
- Явные `[[wikilinks]]` внутри кластера — показать базовый парсинг.
- `--demo` флаг: строит из вшитого `demo/`-вульта в один клик (первое, что видит Даниель).
- Опционально: если Даниель ставит ollama → тот же демо покажет ДОП семантические мосты (апгрейд-эффект).
